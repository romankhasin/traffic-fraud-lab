# Traffic Fraud Lab

Инструмент для локального анализа выгрузок Яндекс Метрики на возможные признаки фрода и низкокачественного трафика.

## Что умеет MVP

- принимает две выгрузки CSV/XLSX: `Источник + IP` и `Источник + технические параметры`;
- автоматически распознаёт русские и английские названия столбцов;
- объединяет данные по UTM Source;
- анализирует поведение, IP/подсети, браузеры, ОС, устройства и разрешения;
- рассчитывает прозрачный risk score от 0 до 100 и уверенность оценки;
- показывает причины оценки и рекомендации по каждому источнику;
- экспортирует рейтинг источников в CSV.

## Приватность

Файлы обрабатываются JavaScript-кодом непосредственно в браузере. Исходные IP-адреса и строки выгрузок не отправляются в репозиторий или на внешний сервер. Для чтения CSV/XLSX используется клиентская библиотека SheetJS с CDN.

## Основные ожидаемые поля

### IP-выгрузка

- UTM Source / Источник;
- IP-адрес;
- Визиты;
- Посетители — необязательно;
- Отказы;
- Время на сайте;
- Доля новых посетителей — необязательно;
- конверсии — необязательно.

### Техническая выгрузка

- UTM Source / Источник;
- Версия браузера;
- Операционная система;
- Модель или тип устройства;
- Разрешение;
- Визиты;
- Отказы;
- Время на сайте;
- конверсии — необязательно.

## Важное ограничение

Результат предназначен для приоритизации ручной проверки. Высокий балл означает сочетание аномальных признаков, а не автоматически доказанный фрод.
